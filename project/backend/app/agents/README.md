## This folder is define all four specialised agents.

### Four agents includes:
1. **`claim_extraction.py`**: Extracts atomic factual claims from AI responses.
2. **`evidence_retrieval`**: Retrieves evidence from trusted organisational documents.
3. **`fact_verification`**: Determines whether claims are supported, contradicted or lack evidence.
4. **`security_assessment`**: Detects potential prompt injection and sensitive information exposure.
